## Notes

This is the first submission of this package to CRAN. The package provides
generalized L-moments estimation methods for extreme value distributions,
implementing both stationary and non-stationary GEV models with various
penalty functions for shape parameter regularization.

The methodology is described in Shin et al. (2025) arXiv:2512.20385.
